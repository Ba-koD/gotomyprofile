# Go To My GitHub Profile Extension

## Privacy Policy (EN)

This Chrome extension does not collect or transmit any personal information or browsing data. It only stores the minimum data it needs, using Chrome's storage API.

### What Data is Stored
- Your settings: the On/Off toggle state and the default profile tab. These are saved in Chrome's sync storage, so they follow your Chrome profile if Chrome sync is turned on.
- Your GitHub username and avatar image URL, read from the github.com page while you are signed in. These are saved only in this browser's local storage.
- No other data is collected, stored, or transmitted.

### Data Usage
- The settings are used solely to remember whether the redirect is enabled and which profile tab to open.
- The username and avatar URL are used solely to show your profile in the extension popup.
- No data is sent to the developer or to any third parties.

### Contact
If you have any questions or concerns about privacy, please contact the developer via the GitHub repository's issue tracker.

## 개인정보처리방침 (KO)

이 크롬 확장프로그램은 어떠한 개인정보나 브라우저 데이터도 수집하거나 전송하지 않으며, 동작에 필요한 최소한의 데이터만 크롬의 storage API로 저장합니다.

### 저장되는 데이터
- 설정값: On/Off 토글 상태와 기본 프로필 탭. 크롬 sync 저장소에 저장되므로, 크롬 동기화가 켜져 있으면 같은 크롬 프로필의 다른 기기에도 동기화됩니다.
- 로그인한 상태의 github.com 페이지에서 읽은 GitHub 사용자 이름과 아바타 이미지 URL. 이 브라우저의 로컬 저장소에만 저장됩니다.
- 그 외의 데이터는 수집, 저장, 전송되지 않습니다.

### 데이터 사용 목적
- 설정값은 리다이렉트 기능 활성 여부와 열 프로필 탭을 기억하는 용도로만 사용됩니다.
- 사용자 이름과 아바타 URL은 확장프로그램 팝업에 내 프로필을 표시하는 용도로만 사용됩니다.
- 어떠한 데이터도 개발자나 제3자에게 전송되지 않습니다.
